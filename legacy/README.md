# Legacy WITR scraper

This directory preserves the original 2017 project unchanged:

- `listsongs.py` scrapes the retired HTML table at `http://logger.witr.rit.edu/?page=N`.
- `cpsong.py` is a Python 2/macOS helper that copies and removes the last line of a song list.
- `dependencies.txt` contains the original dependency pins.
- `songs.txt` is the historical output committed with the project.

Use the Python 3 `listsongs.py` in the repository root for the current WITR site.
